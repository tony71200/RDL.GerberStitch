13.3. Bug #1 (đã sửa, có xác nhận): SampleManifest.cs — kiểm tra ExpectedPath không gate theo requireFiles

Phát hiện: trước khi viết bất kỳ dòng code nào, đã trace toàn bộ call chain SampleManifestValidator.Validate theo đúng yêu cầu Step 5 của brief.
